## 🎯 The Mission
Disrupt the stagnant, ad-ridden monopoly of legacy SMS backup utilities by releasing a privacy-respecting, modern alternative. No ads, no telemetry, no tracking. Just your data, securely backed up.

## 📱 Core Features (MVP Roadmap)
- **SMS & MMS:** Full extraction of texts, group chats, pictures, and audio attachments.
- **Call Logs:** Extraction of incoming, outgoing, and missed call history.
- **Contacts:** Generate .vcf (vCard) files to prevent orphaned phone numbers.
- **Cloud Sync:** Background, scheduled uploads to Google Drive.

## 🛠️ Tech Stack
- **Language:** 100% Kotlin
- **UI:** Jetpack Compose (Material You design language for Android 14/15)

## 🛡️ Privacy First (Open Source)
Since this app requires highly sensitive permissions (READ_SMS, READ_CALL_LOG, READ_CONTACTS), it is entirely open-source. Anyone can audit the code to verify that your data never leaves your device except to your own personal Google Drive.
